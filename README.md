# Atomic Chat WebView

A customized Tauri/WebView build of [Atomic Chat](https://github.com/AtomicBot-ai/Atomic-Chat), designed primarily for mobile use.

This fork tracks the original project while adding Android-specific functionality, desktop-compatible file-based conversation storage, and mobile-focused interface and behavior adjustments.

For the original application, documentation, and releases, visit the [upstream Atomic Chat repository](https://github.com/AtomicBot-ai/Atomic-Chat).
